A tiny Python program that writes one original deadpan weather forecast for the fictional city of Murkwell to /output/entry.txt for make.fun's Deadpan Forecasts for Cities That Do Not Exist bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
